# Architecture Decision Records

Store durable architectural decisions here, one numbered Markdown file per decision (for example, `0001-runner-lifecycle.md`). Keep the record focused on context, the decision, and consequences. Do not use ADRs for ordinary implementation notes; update [architecture.md](../architecture.md) when describing the current system.

Use [the ADR template](0000-template.md). Accepted decisions are historical records: supersede them with a later ADR rather than silently rewriting the decision.
